Este projeto é um gerenciador de tarefas desenvolvido para a disciplina de Front-End Frameworks. A aplicação permite cadastrar, visualizar, concluir e remover tarefas de forma simples e interativa, utilizando apenas HTML, CSS e JavaScript puro.


# Funcionalidades
* Cadastrar uma nova tarefa.
* Visualizar a lista de tarefas cadastradas.
* Marcar tarefas como concluídas.
* Remover tarefas da lista.
* Atualização dinâmica da interface utilizando eventos e manipulação do DOM.


# Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript 
* Git
* GitHub
